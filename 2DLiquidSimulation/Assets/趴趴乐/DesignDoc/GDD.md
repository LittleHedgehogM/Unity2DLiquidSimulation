# 游戏概述

## 游戏名称
萌宠趴趴乐

## 游戏参考
- Tiny Glade
- Summer House
- TownScrapper
- Unpacking
- Gourdlets

## 游戏定位
一款轻松休闲的数字解压玩具，结合摆件陈列、轻度编辑与宠物互动体验。

## 核心体验
- 轻松休闲， 舒服可爱的视觉反馈
- 收集不同的宠物和盒子的乐趣

## 核心循环
玩家在大场景中摆放和整理不同的“趴趴”，观察宠物反应，并通过编辑外壳、内部与宠物配置，逐步打造自己喜欢的展示空间。

## 目标用户
- 喜欢手办、玩偶、桌搭、摆件的人
- 喜欢轻松治愈、低压力互动体验的人
- 喜欢收集、装扮、布置空间的人

# 灵感来源
- 趴趴小玩偶
- 手办陈列
- 桌面摆件
- 轻互动电子宠物

# 游戏视角
2D Isometric

# 核心定义
## 趴趴
“趴趴”既是一个可被陈列的摆件单元，也是一个可被点击和编辑的轻互动对象。
一个“趴趴”由以下三个部分组成：
- 外壳盒子：决定整体外观轮廓、边框样式、主题风格
- 盒子内部：决定内部场景陈列，例如垫子、背景、小装饰
- 宠物：展示在盒子内部的主角，可选正/背面，可交互

# 玩法结构
## 核心循环
1. 浏览大场景中的多个趴趴
2. 拖动、整理、调整陈列位置
3. 点击趴趴或宠物获得反馈
4. 进入编辑模式自定义内容
5. 回到大场景继续观察、互动与陈列

## 游戏目标
- 陈列：把多个趴趴摆放成自己喜欢的布局
- 互动：点击后看到可爱的反馈动画
- 收集：解锁更多外壳、内部主题和宠物
- 表达：搭建自己的专属小展示空间
无失败条件。

# 场景与模式
## 1. 大场景浏览
大场景由多个横竖堆叠摆放的趴趴组成，默认进入大场景浏览状态。
该状态的重点是观察整体陈列效果和获得轻度互动反馈。

玩家可以：
- 浏览整体布局
- 观察宠物待机与轻互动反馈
- 选中单个趴趴
- 进入布局模式或单体编辑模式

### 1.1 场景画布
- 鼠标右键拖拽：移动场景画布
- 鼠标滚轮：放大或缩小画布

目的：
- 方便玩家查看整体布局
- 观察不同位置的趴趴
- 以舒适视角欣赏整体陈列

### 1.2 单个趴趴交互
在大场景浏览状态中，玩家可对单个趴趴进行以下操作：
- Hover：趴趴整体高亮
- 单击：选中趴趴
- 双击：直接进入该趴趴的单体编辑模式
- 点击宠物：播放轻度互动反馈，同时可视为选中该趴趴
- 点击空白区域：取消选中

### 1.3 进入编辑
玩家可通过右上角编辑按钮进入布局模式。

## 2. 布局模式
布局模式用于编辑整体陈列关系，处理多个趴趴之间的位置、数量和组合结构。

进入布局模式后：
- 保留大场景视角
- 显示可吸附边缘、接缝提示与新增位置提示
- 当前 Hover 或选中的趴趴高亮显示

### 2.1 布局模式中的移动
- 拖拽单个趴趴：移动该趴趴的位置
- 趴趴靠近其他趴趴的顶部、左侧、右侧时，可自动吸附
- 放开鼠标后自动对齐到合法位置

### 2.2 布局模式中的新增
- Hover 在趴趴的顶部、左侧、右侧或可连接接缝处时，显示新增按钮
- 点击新增按钮后，在对应方向生成一个新的趴趴
- 新增的趴趴默认使用基础盒型和默认宠物配置，后续可再编辑

### 2.3 布局模式中的删除
- Hover 单个趴趴时，显示修改/删除入口
- 点击删除后移除该趴趴
- 若该趴趴承担上层堆叠结构，首版建议禁止直接删除，并提示玩家先移走上方趴趴

### 2.4 布局模式中的修改入口
- 单击：选中趴趴
- 双击：进入该趴趴的单体编辑模式
- Hover 后显示修改按钮，点击也可进入单体编辑模式

### 2.5 退出布局模式
- 点击完成/返回按钮：退出布局模式，回到大场景浏览
- 按 Esc：退出布局模式，回到大场景浏览

## 3. 单体编辑模式
单体编辑模式用于放大查看并编辑单个趴趴的内容，不处理整体布局。

进入方式：
- 大场景浏览时，双击单个趴趴
- 布局模式中，双击单个趴趴
- 布局模式中，点击 Hover 后显示的修改按钮

进入单体编辑模式后：
- 相机 Zoom In 到当前趴趴
- 当前趴趴保持高亮
- 其他趴趴弱化显示
- 打开右侧编辑面板

### 3.1 Box Tab
用于修改盒子相关内容：
- 套装
- 外壳形状
- 外壳样式
- 颜色
- 边框

交互建议：
- 点击盒体或边框时，默认切换到 Box Tab
- 所有修改即时预览

### 3.2 Pet Tab
用于修改宠物相关内容：
- 种类
- 皮肤/颜色
- 朝向

交互建议：
- 点击宠物时，默认切换到 Pet Tab
- 宠物修改结果即时预览

### 3.3 退出单体编辑模式
- 点击返回按钮：退出单体编辑，回到布局模式
- 按 Esc：退出单体编辑，回到布局模式

## 4. 模式切换
| 当前模式 | 操作 | 目标模式 |
|---------|------|---------|
| 大场景浏览 | 点击编辑按钮 | 布局模式 |
| 大场景浏览 | 双击趴趴 | 单体编辑模式 |
| 布局模式 | 双击趴趴 | 单体编辑模式 |
| 布局模式 | 点击修改按钮 | 单体编辑模式 |
| 单体编辑模式 | 点击返回或按 Esc | 布局模式 |
| 布局模式 | 点击完成或按 Esc | 大场景浏览 |

# 宠物
## 基础属性
- 类别
- 外观皮肤
- 朝向
- 动画状态组
- 交互动作组

## 宠物朝向
宠物可配置以下表现：
- 正面：3/4侧面趴下
- 背面：背面重点展示屁屁、脚部与尾部等可爱特征

## 宠物状态
- 待机(不同动画组)
- 点击反馈
- 转身
- 互动

# 盒子
## 盒子形状选择
- 标准长盒形 1X1X2
- 甜甜圈形
- 其他形状（待定）

## 边框
可修改样式

## 盒子主题
- 玩家可以选择整套已配置好的主题
套装是一整套set， 包含
外壳形状
外壳样式（颜色）
外壳透明度
边框样式


# 自定义
玩家可选择自定义样式和宠物
