# 美术出图需求

## 需求名称
罐头熊基础款概念图

## 需求目标
为《萌宠趴趴乐》首批内容制作一个可作为基准风格参考的“趴趴”概念图。

本次需求聚焦于：
- 一只趴着的玩具熊
- 被装在一个罐头盒中
- 罐头开口面朝前
- 同时产出正面图和背面图
- 统一为游戏内使用的 2D 等距视角表达

该图的目的不是做纯插画海报，而是作为后续游戏内宠物、盒体和主题套装的视觉基准。

## 项目上下文
结合 GDD，本项目的“趴趴”是一个可陈列、可互动、可编辑的宠物商品单元，由以下部分组成：
- 外壳盒子
- 盒子内部小场景
- 宠物主体

玩家看到的感受应该是：
- 一个可摆上货架的小商品
- 一个有包装设计感的潮玩摆件
- 一个低压力、可爱、想点击互动的小宠物

## 本次对象定义
### 宠物
- 品类：玩具熊
- 姿态：趴着，身体压扁，重心低，呈柔软团块感
- 气质：可爱、无攻击性、像毛绒玩具或潮玩公仔，不偏真实熊
- 比例：头部略大，身体宽短，四肢短，整体偏圆润

### 盒子
- 品类：罐头
- 视觉定位：像一个专门售卖玩具熊的可收藏罐头商品
- 朝向要求：罐头开口正面朝向镜头，玩家能直接看到内部的熊
- 罐头不是写实食品罐头，而是更偏插画化、设计化、潮玩包装感

## 视角要求
### 总体视角
- 使用 2D isometric 基础视角
- 表达上参考你当前使用的等距格线和盒体草图
- 镜头需要同时看见：
  - 罐头正面开口
  - 罐头部分顶部
  - 罐头一侧侧面

### 构图要求
- 单体居中
- 主体完整，不裁切
- 尽量保留足够留白，方便后续作为设定参考
- 背景建议纯色或透明背景

### 形体关系
- 罐头盒是一个有厚度的长方体罐头/包装盒
- 开口面朝前，内部像一个展示窗
- 熊被安置在罐头内部，身体略微顶住前开口边缘，增强“被包装起来”的感觉

## 正面图要求
### 宠物朝向
- 玩具熊以正面 3/4 趴姿面向玩家
- 重点看到脸、耳朵、前爪和胸前轮廓
- 表情克制，偏呆萌，不要过于兴奋

### 可爱重点
- 脸部居中偏低
- 鼻子和嘴部简化
- 前爪自然搭在身体前方或轻轻靠近开口边缘
- 看起来像一只柔软地趴在罐头里的展示玩具

## 背面图要求
### 宠物朝向
- 玩具熊以背面趴姿朝向盒内深处
- 重点展示后脑勺、背部、屁股、后腿和短尾巴
- 背面仍要保有“想点一下”的可爱吸引力

### 可爱重点
- 屁股和尾巴是视觉卖点
- 后腿略向两侧摊开，延续“趴趴”的柔软感
- 轮廓应与正面图区分明显，但保持同一只熊的设计一致性

## 风格要求
结合项目现有美术设计文档与参考图，风格统一为：
- 清晰外轮廓
- 深色线稿
- 平涂为主
- 少量柔和阴影
- 图形概括强
- 商品包装感明确
- 色彩鲜明但不杂乱
- 可爱潮玩感强

### 线条
- 线稿清晰干净
- 轮廓线有存在感
- 不追求复杂纹理线和写实毛发

### 上色
- 以平涂色块为主
- 阴影只保留一层主阴影和少量接触阴影
- 可以在罐头金属边、透明贴膜、标签区域加入少量高光

### 材质表现
- 玩具熊：毛绒玩具 / 潮玩玩偶感，避免写实毛发
- 罐头：带一点金属或包装盒质感，但仍以插画化概括为主
- 内部空间：像被装在包装中的小舞台，而不是写实容器内部

## 罐头设计要求
### 造型方向
- 基础轮廓接近长方体包装罐头
- 前方有明显开口/展示窗
- 边框较厚，强化商品边界
- 可以有轻微圆角，提升可爱度

### 包装设计元素
- 可以在顶部、侧面或边角加入少量商品化元素：
  - 标签
  - 小图标
  - 简单品牌贴纸
  - 条纹或色块

控制原则：
- 点到为止
- 不要信息过载
- 不能抢过玩具熊主体

## 推荐配色
本次基准款建议优先使用一套温暖、容易建立“可购买商品感”的配色：

### 方案 A
- 玩具熊：奶茶棕 / 焦糖棕 / 米白
- 罐头：奶油白 + 番茄红 + 少量暖黄
- 线稿：深棕或近黑色

### 方案 B
- 玩具熊：蜂蜜棕 / 浅卡其 / 豆沙粉内耳
- 罐头：薄荷绿 + 奶油白 + 橙红标签
- 线稿：深灰棕

如果只出一版，请优先方案 A。

## 内部场景建议
本次以“最简基础款”为主，不需要复杂主题场景。

内部只需保留：
- 一个简化底垫
- 一个浅色背景面
- 极少量包装内衬感细节

目标是突出：
- 熊本体
- 罐头商品感
- 开口展示结构

## 输出内容
需要产出两张图：

1. 正面图
- 等距视角
- 罐头开口朝前
- 熊为正面 3/4 趴姿

2. 背面图
- 等距视角
- 罐头开口朝前
- 熊为背面趴姿

## 出图限制
避免以下问题：
- 不要写实动物风
- 不要做成恐怖罐头或猎奇食品包装
- 不要把熊画成站立或坐姿
- 不要把罐头画成纯圆柱标准食品罐，优先接近游戏中的盒状包装单元
- 不要使用过强透视，必须保持等距视角稳定感
- 不要加入复杂背景
- 不要把内部塞满道具

对象 + 视角 + 动作/朝向 + 盒体描述 + 风格母 Prompt + 配色 + 限制词
