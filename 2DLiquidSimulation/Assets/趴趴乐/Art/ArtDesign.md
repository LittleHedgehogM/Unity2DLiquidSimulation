# 美术设计

## 视觉定位
《萌宠趴趴乐》的整体美术方向是“可购买的宠物潮玩陈列”。玩家看到的不是一组组像商品、盲盒、罐头玩具、展示盒一样被包装起来的小宠物单位。

每一个“趴趴”都应该同时具备以下三层感受：
- 像一个已经设计完成、可以被摆上货架的商品
- 像一个可爱、轻松、低压力的宠物小窝
- 像一个平面插画风很强的潮玩展示盒

大场景的观感不是“搭房子”或“拼地块”，而更接近“整理一整面商品陈列柜”或“布置一个收藏展示架”。

## 核心概念
### 1. 趴趴 = 被包装起来的宠物商品
一个趴趴由外壳盒子、内部陈列和宠物组成。视觉上要让玩家第一眼就理解它是一个完整的商品单元，而不是松散拼起来的几个素材。

设计重点：
- 外壳决定商品属性，要有明确包装感、标签感、边框感
- 内部决定主题氛围，要像一个被缩进盒子里的迷你舞台
- 宠物是视觉焦点，要像包装中最吸引人视线的主角

### 2. 大场景 = 商品陈列墙 / 收藏展示柜
多个趴趴组合后，应形成强烈的“陈列”感。参考超市货架、盲盒墙、玩具店陈列、桌面收藏架的视觉印象。

设计重点：
- 单个趴趴既独立成立，又能在堆叠后形成整齐节奏
- 相邻趴趴之间要有包装边缘、接缝、标签错落带来的图形美感
- 整体画面优先追求“摆得可爱、看着舒服、颜色丰富但不乱”

### 3. 风格气质 = 轻松可爱 + 图形感强 + 有商品设计意识
从参考图看，项目不适合写实、厚涂、材质堆叠很多的方向，而更适合：
- 轮廓明确
- 造型概括
- 平涂为主
- 少量阴影辅助体积
- 颜色鲜明但整体和谐
- 带一点插画贴纸、包装印刷和玩具品牌视觉的感觉

## 参考图提炼
根据参考板，当前可归纳出几条明确的视觉共性：

### 1. 轮廓清晰，黑色或深色线稿有存在感
很多参考图都依赖清楚的外轮廓建立角色识别度，线条不是写实结构线，而是服务于图形归纳和可爱感的设计线。

落地建议：
- 角色、盒体、道具都尽量保持清楚的外轮廓
- 线条粗细统一，不做过多笔触变化
- 阴影不要抢轮廓的功能，优先让剪影成立

### 2. 颜色鲜艳，但不是高饱和乱堆
参考图大量使用粉、橙、黄、湖蓝、青绿、奶油白、紫灰这类高识别色，但通常会配一组主色和几个点缀色，而不是全部同时发力。

落地建议：
- 每个主题盒控制在 1 个主色 + 1 个辅助色 + 1 个点缀色
- 宠物本体颜色应比包装更集中，避免主体被环境吞掉
- 大场景中允许丰富，但单个趴趴内部要控制配色数量

### 3. 造型偏扁平图形化，但保留少量体积
参考图并非完全平面 icon 风，而是在平涂基础上保留少量明暗关系，让物体有“玩具”和“包装物”的体积感。

落地建议：
- 使用 1 层主阴影 + 少量接触阴影即可
- 高光只用于塑料窗、金属边、贴膜、罐头等少数材质
- 不追求复杂光照统一，优先保证读图轻松

### 4. 宠物形体以“团、趴、软、短”优先
参考板中的猫和小动物普遍拥有很强的“趴着不动也可爱”的特征，适合本项目的静态陈列和轻互动玩法。

落地建议：
- 身体尽量压扁、放宽，重心低
- 脸部五官集中，眼睛可适当偏大
- 爪子、尾巴、屁股等局部可以成为卖点
- 正面和背面都要有明确的可爱识别点

## 美术表现原则
### 1. 优先商品感，其次生活感
每个趴趴首先是一个“被设计过的商品”，然后才是一个“宠物生活空间”。所以包装结构、边框、标签、窗洞、盒体轮廓必须足够明确。

### 2. 优先图形统一，不追求材质真实
项目更适合“插画商品”而不是“真实玩具渲染”。材质表现要点到为止，避免让画面变脏、变重。

### 3. 优先可爱剪影，不堆内部细节
宠物和盒体在缩小后仍需一眼看懂。轮廓、朝向、耳朵、尾巴、窗洞、边框这些一级信息，比纹理和装饰细节更重要。

### 4. 优先轻松治愈，不做攻击性视觉
即使某些主题可以做幽灵、骷髅、暗黑魔法，也应保持“可爱、玩具化、无威胁”的表达，不走恐怖或压迫路线。

## 盒体设计语言
### 盒体作用
盒体是“趴趴”最重要的识别外壳，承担商品包装、陈列边界和视觉统一三重功能。

### 盒体关键词
- 罐头盒
- 展示盒
- 开窗包装
- 礼盒
- 小卖部零食盒
- 玩具包装
- 收藏盒

### 造型特征
- 以圆角矩形、矮胖长盒、厚边框盒为主
- 轮廓规整，但允许局部做主题化变化
- 正面保留清晰“开窗”区域，方便看见宠物主体
- 盒体边缘可加入标签、扣边、封条、提手、印花边框等包装元素

## 宠物设计语言
### 宠物定位
宠物不是写实动物，而是更接近“玩偶化、贴纸化、IP 化”的可收藏角色。

### 造型原则
- 大轮廓尽量接近椭圆、团块或吐司状
- 四肢短，身体宽，头身融合度高
- 表情克制，不做太复杂的五官运动
- 单体轮廓在小尺寸下仍有辨识度

### 朝向设计
正面重点：
- 脸、耳朵、前爪
- 适合表现呆萌、无辜、软趴感

背面重点：
- 屁股、尾巴、后腿
- 适合表现收藏感和“想点一下”的互动欲望

### 场景观感
- 像一张插画切片
- 像一个被装进盒子里的迷你橱窗
- 像一个为主角量身定制的小背景板

## UI 与图形装饰倾向
虽然本文主要描述场景和角色，但从参考图看，项目的 UI 也应该尽量延续包装图形语言。

建议方向：
- 标签贴纸感按钮
- 圆角卡片
- 高识别图标
- 像包装说明书一样的分类标签
- 像商品系列卡一样的主题预览图
